\begin{abstract}
A model-processing pipeline can change conformance when name binding, inherited
property identity or repeated reference occurrences are lost between tools.
We formalize a stated static structural fragment of EMOF 2.5.1 in Lean 4,
separating symbolic source satisfaction, actual elaboration, finite Core
conformance and executable decisions. For lexically admissible source documents, satisfaction is equivalent to
successful elaboration to an accepted Core snapshot. Checker acceptance is
equivalent to Core conformance over all represented inputs. The development proves finite
reachability completeness and occurrence-sensitive transport, and applies the
common checker to a bounded metadata interpreter. A real EMF bridge constructs
fresh resources and compares reloaded observations under an explicit identity
bijection. Authored separating tests and six explicitly adapted Train snapshots
exercise the executable boundary. The guarantee is bounded: standards
interpretation, parsing and native adapters remain separate trust obligations;
reflective behavior and full EMOF self-description are not claimed.
\keywords{EMOF \and Metamodeling \and Lean \and Model conformance}
\end{abstract}
