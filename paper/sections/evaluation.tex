\section{Evaluation}
\subsection{Evidence and Research Questions}
The evaluation separates source justification, formal consequences and runtime
observations. The artifact retains commands, input hashes, tool versions,
diagnostics and raw measurements. Historical Train round-trip records remain
separate from the new validator comparison: load/save success is not validation,
and Train's domain-query timings are not a baseline for structural conformance.

\paragraph{RQ1: Source interpretation.}
Kernel-checked examples separate structural $0..0$ validity from positive-upper
creation bounds: empty observations conform, nonempty ones fail, and the class
fails creation bounds. Four containment cases separate repeated unpaired
occurrences (accepted), two parents (rejected), two unpaired features from one
parent (accepted), and two paired active container roles (rejected). The last
fails only ownership in a well-formed schema. A diamond example counts inherited
identifier declarations once by identity. These answer RQ1 within the selected
fragment; the deferred source-encoding findings are not implemented fixes.

\paragraph{RQ2: Reusable formal results.}
The Lean build checks Equations~\ref{eq:checker} and~\ref{eq:adequacy}, finite
reachability results and semantic examples. Source preservation/reflection
transport both ownership obligations through actual allocations; optimized
representative-key tests are equivalent to pairwise predicates without assuming
conformance. Opposite-upper-one bounds forward occurrence counts across
metamodels, and observation-key injectivity makes conforming rows functional.
The metadata example reuses checking while separately validating interpreted
schemas. These establish bounded reuse, not parser/codec correctness or full
self-description.

\subsection{Published Case and Actual EMF Validation}
The Train projection in Section~2 has five authored objects and thirteen
applicable observations. Its complete source is accepted. Reusing an ordinary
integer \emph{id} value on two objects remains accepted; removing one required
sensor is rejected for multiplicity, and removing the inverse route value is
rejected for opposite counts. These are structural consequences of the mapped
metamodel. No Train domain query is evaluated.

The comparison uses EMF Ecore/XMI 2.39.0 with Common 2.42.0. An isolated registry
selects EcoreValidator for schema objects and the generic EObjectValidator for
dynamic instances. Diagnostician validates schema roots and instance roots
separately; results retain both phases and diagnostic codes. Generated domain
validators and OCL delegates are not part of this condition. The bridge's
representation restrictions remain separate from validator outcomes.

A positive generic model is accepted by both systems. Both reject a missing
required String and an inconsistent interval with lower one and upper zero.
The zero-upper schema illustrates a domain difference: EMF's schema validator
rejects upper zero, whereas the structural EMOF interpretation accepts its empty
interval. Nonunique multivalued containment schemas are likewise rejected by
Ecore's schema-level uniqueness restriction; this is not evidence of an
instance-container disagreement. A unique String list containing equal repeated
values produces another difference: the loaded native list retains both values,
its generic validator accepts, and VL-MOF rejects uniqueness. Its cause must be
read in the context of the pinned validator and loaded state, not generalized
to all EMF editors or generated validators.

\paragraph{RQ3: Outcomes and bounded cost.}
Before timing, the harness compares loaded feature observations with normalized
Core rows through recorded native identities, including occurrence order and
absence. The five-object Train projection and three-object generic positive pass.
A retained public Train input with 754 objects validates in EMF, but twelve
unset enumeration features become explicit \texttt{FAILURE} values in Core.
This normalization loss excludes that input from paired timing; native validation
alone cannot establish equal input states.

The aligned positives receive ten warmups and thirty measured repetitions in
separate preloaded processes on Linux under WSL2, with Java~21. Both timed paths
return Booleans for combined schema and instance validation; diagnostic reporting,
startup, loading, conversion and serialization are outside this boundary. VL-MOF
includes a small result-cell forcing overhead. All measured results are true.
Table~\ref{tab:validation-time} reports medians and ranges; the artifact retains
individual repetitions, means, sample deviations, toolchain and machine details.

Thus RQ3 establishes working structural examples, observed agreements and
explicitly classified differences, plus reproducible costs for two small aligned
states. It does not establish scalability or a general performance advantage.
The larger public input exposes the next interoperability requirement: represent
and align default presence before extending the matched timing corpus.
