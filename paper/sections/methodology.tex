\section{Formalization}\label{sec:formalization}


\subsection{Scope and Representation}
We define finite structural states and their conformance before proving the
connections to checking and named declarations. Reflective operations are excluded.
\begin{definition}[Schema and snapshot]\label{def:representation}
We describe a metamodel as a \emph{schema} $S$ and a finite model state as a
\emph{snapshot} $M$; together they form the internal representation, \emph{Core}.
A schema declares packages, classes, inheritance, properties, binary associations
and enumerations. A snapshot records objects, their classes and property values.
\end{definition}
Inheritance collects reachable superclass properties by declaration identity:
a diamond shares a declaration; same-named distinct declarations remain separate.
Qualified aliases select declarations without overriding. This combines UML
inheritance \cite[\S9.9.4]{omg_uml_25} with EMOF property access
\cite[\S12.5.4]{omg_mof_251}; inheritance cycles are rejected.
An observation $(o,p,L)$ records a finite value sequence for object $o$ and
property $p$. Lookup $L_M(o,p)$ concatenates all matching rows, or is empty
if none exist. This defines lookup on malformed inputs too; conformance requires
exactly one row per applicable pair, distinguishing missing from empty rows.

Values are object references, Booleans, integers, strings or enumeration literals;
conformance requires XML-valid strings. Properties specify bounds, ordering,
uniqueness and composition. Opposites are association ends; association-owned
nonnavigable ends record incidence, and packages share an implicit outer scope.

\subsection{Structural Conformance and Source Requirements}\label{sec:conformance}
Schema well-formedness $W(S)$ requires distinct, resolved identities, valid names,
acyclic package and inheritance graphs, and consistent ownership, types, bounds and association
ends. At most one identifier property is allowed across direct and inherited
declarations; this does not require globally unique values. Train's \emph{id}
has no identifier flag.

\begin{definition}[Structural conformance]\label{def:conformance}
A snapshot $M$ conforms to a schema $S$, written $C(S,M)$, when $W(S)$ holds
and the following obligations hold: object identities are distinct and classifiers
are resolved and concrete; observations have resolved, applicable keys, with
exactly one row per applicable pair; values satisfy typing, multiplicity and
uniqueness; opposite occurrence counts agree; containment has at most one parent, at most
one active reverse container property, and no cycles.
\end{definition}
Applicability follows inheritance or association ownership. False, zero and the
empty string count as values. We detail the principal conditions below.

Following UML's collection bounds and uniqueness
\cite[\S\S7.5.3.2,11.5.3.1]{omg_uml_25}, each applicable property $p$
with bounds $\ell_p,u_p$ at object $o$ must satisfy
\[
 \ell_p\leq |L_M(o,p)|\ \land\
 (u_p=\ast\ \lor\ |L_M(o,p)|\leq u_p),
 \qquad \mathit{unique}_p\Rightarrow\operatorname{distinct}(L_M(o,p)).
\]
Here $\ast$ means unlimited; length counts occurrences and $\operatorname{distinct}$
excludes repeats. References compare by identity. Observation comparison preserves
ordered sequences and compares unordered values up to permutation; it is separate
from conformance.

\paragraph{Opposites.}
Write $\#_v(L)$ for the number of occurrences of value $v$ in sequence $L$.
Our subset represents associations through endpoint observations, without
first-class link identities. It imposes equal forward and reverse occurrence
counts for opposite properties $p,q$ and objects $x,y$:
\begin{equation}
 \#_{\operatorname{ref}(y)}L_M(x,p)
 = \#_{\operatorname{ref}(x)}L_M(y,q).
\label{eq:opposite}
\end{equation}
For Train's unique references, this checks reciprocal membership; for two
nonunique ends, it retains repeated-pair counts. Mixed uniqueness is restricted:
UML projection can yield $\langle y,y\rangle$ at a nonunique end and
$\langle x\rangle$ at its unique opposite \cite[\S11.5.3.1]{omg_uml_25},
but Equation~\ref{eq:opposite} rejects that pair. This is an additional subset
restriction. CMOF's repeated-link rationale \cite[\S13.2.5]{omg_mof_251}
does not establish equal counts for all EMOF opposites.

\paragraph{Containment.}
Following MOF \cite[\S12.5.5]{omg_mof_251}, composite observations of a child
must name one parent, with at most one nonempty reverse container property.
Repeated unpaired occurrences do not add parents. No nonempty composite path
may return to its source. Multiplicity and uniqueness are checked separately.

\begin{proposition}[Upper-one opposite]\label{prop:opposite}
Suppose $C(S,M)$, a stored association has ends $(p,q)$, and the stored declaration
of $q$ has upper bound one. For stored objects $x,y$, with $q$ applicable at $y$,
each forward reference count is at most one, even if $p$ is nonunique.
\end{proposition}
\begin{proof}
Opposite agreement and the upper bound give
\[
 \#_{\operatorname{ref}(y)}L_M(x,p)
 =\#_{\operatorname{ref}(x)}L_M(y,q)
 \leq |L_M(y,q)|\leq 1.
\]
\end{proof}
The bound limits repetitions per target. It follows from our equal-count
restriction and is not asserted for UML's mixed-uniqueness projection.

\subsection{Verified Checking and Translation}\label{sec:guarantees}
\begin{theorem}[Checker correctness]\label{thm:checker}
For every raw schema $S$ and snapshot $M$, including malformed inputs,
\begin{equation}
 \operatorname{check}(S,M)=\mathsf{true}
 \quad\Longleftrightarrow\quad C(S,M).
\label{eq:checker}
\end{equation}
\end{theorem}
\begin{proof}[Outline]
Combine predicate/decision equivalences, including optimized-closure correctness.
The separate closure-to-path results are not needed here.
\end{proof}
An analogous theorem decides $W(S)$. These are soundness and completeness
results for the defined predicates, without a runtime complexity claim.

\paragraph{Symbolic declarations and elaboration.}
Parsing produces a symbolic AST $d$. Its independent satisfaction predicate
$\mathcal S(d)$ uses paths, applicability, typing, opposite counts and containment,
without calling the checker, elaborator or $C$; elementary string-validity and
multiplicity notions are shared. The elaborator $E$ resolves qualified aliases,
allocates identities by declaration kind and list position, and translates values.
Let $A(d)$ require nonempty declaration and object aliases with nonempty
XML-valid components. Successful binding alone does not establish this lexical
condition, which does not assume conformance.

\begin{theorem}[Source adequacy]\label{thm:adequacy}
For every symbolic document $d$,
\begin{equation}
 A(d)\Longrightarrow\left(
 \mathcal S(d)\ \Longleftrightarrow\
 \exists S,M.\ E(d)=\mathsf{ok}(S,M)\land
 \operatorname{check}(S,M)=\mathsf{true}\right).
\label{eq:adequacy}
\end{equation}
\end{theorem}
\begin{proof}[Outline]
Preservation constructs an elaborated, conforming pair from source satisfaction.
Reflection recovers source satisfaction from checker acceptance, using $A(d)$
for alias validity. Both transport paths, applicability, values and containment;
closure-to-path equivalences connect finite reachability to source paths.
\end{proof}
For a successfully elaborated pair, $A(d)$ also gives $\mathcal S(d)\iff C(S,M)$.
Parsing and arbitrary Core representability remain outside these results.
