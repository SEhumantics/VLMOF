\section{Methodology}
\subsection{A bounded interpretation of EMOF}
Figure~\ref{fig:semantics} connects structural meaning to authoring and checking.
The audit records whether each of MOF 2.5.1 Clause~12.4's 32 restrictions is
enforced, excluded, or deferred; adopted UML supplies generalization and
inheritance \cite{omg_mof_251,omg_uml_25}.

The structural finite domain includes packages, classes and multiple inheritance,
properties, binary associations, selected primitive/enum values, multiplicity,
ordering, uniqueness, opposites and containment. One association end may be
association-owned and nonnavigable; its observation denotes incidence. Values are
Boolean, arbitrary Integer and XML-valid String; Real, structured datatypes,
operations, defaults/unset histories, derived behavior, comments and reflection
are deferred.

Structural upper bounds are no smaller than lower bounds; $0..0$ permits an
empty collection under adopted UML. MOF~9.3.3 instead requires an upper bound
admitting one in its creation context. A separate query records that prerequisite
without implementing creation. Nonunique references retain repeated occurrences; static
acceptance does not assert reflective reachability.

\subsection{Identity-based schemas and snapshots}
A schema $S$ contains finite package, class, property, association, enumeration
and literal declarations with distinct identity types; names are metadata. The
implicit root scope is not a materialized reflective package graph. A snapshot
$M$ has objects and rows $(o,p,L)$ of primitive, enum or reference occurrences.
Raw records can retain duplicate identities, dangling references and duplicate
keys for later rejection.

Schema well-formedness $W(S)$ requires unique/resolved identities, valid names,
acyclic package and inheritance graphs, ownership/type/multiplicity/end
consistency, and at most one inherited identifier property. Applicability uses
an owning ancestor or an applicable association-owned end; ancestor closure is
deduplicated by declaration identity. Thus \emph{Switch} inherits one
\emph{RailwayElement.id}, and a diamond still exposes one identity.

Snapshot conformance $C(S,M)$ includes $W(S)$, unique object IDs and observation
keys, concrete resolved classifiers, and one row per applicable pair. \texttt{[]} is
zero occurrences: absence for an optional scalar/reference or an empty
multivalued collection, distinct from false, zero and empty String. Occurrences
are typed; lengths meet bounds; unique properties have no equal values; reference
equality is object identity. Observation equivalence compares ordered lists as
sequences and unordered lists up to permutation; it is not conformance.

For an applicable property declaration $p$ and stored object $o$, the local
obligations include
\[
 \ell_p\leq |L_M(o,p)|\ \land\
 (u_p=\ast\ \lor\ |L_M(o,p)|\leq u_p),
 \qquad \mathit{unique}_p\Rightarrow\operatorname{Nodup}(L_M(o,p)).
\]
Each member must match the declared type; bounds, uniqueness and typing are
separate obligations.

For an association with opposite properties $p$ and $q$, let $L_M(o,p)$
be the occurrences observed for object $o$ at $p$. For every object pair
$x,y$, conformance requires
\begin{equation}
 \#_{\operatorname{ref}(y)}L_M(x,p)
 = \#_{\operatorname{ref}(x)}L_M(y,q).
\label{eq:opposite}
\end{equation}
In Figure~\ref{fig:train}, a position occurs at the route's \emph{follows}
end exactly as often as that route occurs at the position's \emph{route} end.
For containment, write $a\triangleright t$ when observation row $a$ contains a
reference to child $t$ through a composite property, and $K(p)$ when $p$ is an
explicit opposite of a composite end. The implemented pairwise obligations are
\begin{align*}
 a\triangleright t\land b\triangleright t
   &\Rightarrow a.\mathit{object}=b.\mathit{object},\\
 \left.\begin{gathered}
 a.\mathit{object}=b.\mathit{object}=t,\\
 K(a.p)\land K(b.p),\quad a.L\ne[]\land b.L\ne[]
 \end{gathered}\right\}
   &\Rightarrow a.p=b.p.
\end{align*}
Both quantify over stored rows: the first constrains parent identities and the
second active reverse-property identities. Acyclicity forbids a nonempty
composite path back to its source. Thus repeated unpaired occurrences can have
one parent, while two active reverse roles can fail the second rule.

\subsection{A reusable consequence}
Suppose $C(S,M)$, a stored association has ends $(p,q)$, and its stored declaration
of $q$ has upper bound one. Let $x,y$ be stored objects with $q$ applicable at
$y$. The library proves
\[
 \#_{\operatorname{ref}(y)}L_M(x,p)
 =\#_{\operatorname{ref}(x)}L_M(y,q)
 \leq |L_M(y,q)|\leq 1.
\]
Reciprocity gives equality, counting gives the length bound, and conformance the
reverse multiplicity bound. This limits repetitions per target, not the number
of targets; forward uniqueness is not a premise. The stored declaration, object
and reverse-applicability premises are material, so the result rules out an edit
without enumerating conforming snapshots.

\subsection{A complete finite decision}
Finite reachability for inheritance, packages and containment expands adjacent
identities, discards those seen, and stops at carrier size. Well-formedness and
resolution keep paths in that carrier; each unstabilized expansion adds a fresh
identity. Every computed identity has a stored path. The early fixed-point
optimization returns the same closure. This is a
completeness argument, not a practical runtime bound.

The executable schema and snapshot checks are Boolean conjunctions of these
finite obligations. Their correctness statements are unconditional over the raw
representation:
\begin{equation}
 \operatorname{check}(S,M)=\mathsf{true}
 \quad\Longleftrightarrow\quad C(S,M),
\label{eq:checker}
\end{equation}
with an analogous equivalence for $W(S)$. The diagnostic interface reports
the failed conjuncts; it does not claim to compute a minimum repair.

\subsection{Independent source meaning and elaboration}
The symbolic source document $d$ uses qualified declaration and object aliases.
Its independently defined satisfaction relation $\mathcal S(d)$ uses path
relations, applicability, typing, opposite counts and containment, without
calling the Core checker, elaborator or $C$.

Elaboration $E$ checks global alias uniqueness/qualification, resolves symbolic
references, allocates per-kind list-position identities, and translates values.
Its proof transports reachability, applicability, list facts and containment
through alias-to-identity correspondence.

Let $A(d)$ require declaration and object aliases to be nonempty, with nonempty
XML-valid components. The binder checks nonemptiness; source satisfaction adds
character validity. This contains no conformance premise. The connection is
\begin{equation}
 A(d)\Longrightarrow\left(
 \mathcal S(d)\ \Longleftrightarrow\
 \exists S,M.\ E(d)=\mathsf{ok}(S,M)\land
 \operatorname{check}(S,M)=\mathsf{true}\right).
\label{eq:adequacy}
\end{equation}
The forward direction obtains elaboration; the reverse reflects conformance
through actual bindings. A fixed-result form equates $\mathcal S(d)$ and
$C(S,M)$ under exhibited successful elaboration.
