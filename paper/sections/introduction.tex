\section{Introduction}
When a modeler writes a model and a tool accepts it as conforming, which model
has actually been checked? The authored document refers to declarations by
symbolic names. A conformance algorithm works more naturally with resolved
identities and finite tables. An interchange tool may allocate those identities
again. For structural EMOF, the question reaches beyond name lookup: inherited
properties are declarations rather than copied strings, opposite ends constrain
the same relationship from two directions, and multiplicity counts occurrences.

This paper develops VL-MOF, a Lean 4 account of a stated static structural
profile of EMOF 2.5.1. The profile is drawn from a clause-by-clause reading of
the standard and adopted UML material. It covers packages, classes, multiple
inheritance, properties, binary associations, primitive and enumeration values,
multiplicity, order, uniqueness, opposites, and static containment. Operations,
general structured datatypes, reflective services, defaults, and behavioral
features are outside the profile.

The main contribution is a connected account of authored meaning and decidable
conformance. First, a finite identity-based semantics states what well-formed
schemas and conforming snapshots are. Second, a Boolean checker is proved to
decide those predicates on every represented input, including malformed raw
records. Third, the symbolic source language has its own satisfaction relation,
defined without the checker, and the actual elaborator is proved to preserve and
reflect that relation under a small lexical premise. Thus acceptance can be read
back as a statement about the authored abstract syntax, rather than only about
the elaborator's output.

Figure~\ref{fig:catalog} introduces one catalog model used throughout the paper.
It makes the central connection tangible: the author writes aliases such as
\texttt{Book::authors}; elaboration assigns declaration and object identities;
conformance then checks the resulting occurrence lists, including their
opposites and containment. The same semantic account is reusable for any model
inside the profile. A bounded metadata interpreter demonstrates this reuse
inside Lean. A restricted EMF bridge supplies empirical evidence that a native
Ecore/XMI route can preserve the selected observations when accompanied by an
explicit identity map.

Executable MOF semantics, mechanized preservation results, and textual
metamodeling languages precede this work
\cite{boronat_meseguer_2010,kezadri_etal_2014,jouault_bezivin_2006}.
The result here is the proved connection between an independently specified
symbolic meaning, actual elaboration, and a complete decision procedure for the
selected profile.

We ask three questions. RQ1 asks whether semantics sensitive to identities and
occurrences has a complete finite decision procedure. RQ2
asks whether actual symbolic elaboration preserves and reflects that semantics.
RQ3 asks how much of this account survives a real, deliberately narrower EMF
realization.
